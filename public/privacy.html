About & privacy

G.tok helps you discover recently created GitHub repositories, sorted by total stars. This is not GitHub's Trending feed or a measure of recent star growth.

Aggregate opens, not people

When you open a repository using its title, Open button, README panel's GitHub link, or O shortcut, G.tok sends only its repository name to our backend. We increment a daily total for that repository. We do not create visitor IDs, use analytics cookies, fingerprint browsers, or store IP addresses or browsing histories in our application database.

These totals count opens, not unique visitors or confirmed visits on GitHub. Repeated clicks can count more than once. Counts are best effort, can be blocked or automated, and do not drive recommendations yet. Daily totals are removed after 30 days by a daily cleanup job.

What stays on your device

Saved repositories and the list of repositories you've already seen live in this browser's local storage. We do not upload them. Clear site data in your browser to remove them. No account or login is required.

GitHub and Cloudflare

Our Cloudflare Worker caches GitHub search results for 15 minutes and README text for 6 hours. It may serve older cached content when upstream services are unavailable. Avatars and images inside READMEs load directly from GitHub or their original image hosts. Opening external links connects you to those sites.

Cloudflare delivers this site and necessarily processes network information, including IP addresses. Its infrastructure security and operational data handling is separate from our aggregate-only application database. We have disabled Worker request logging and have not added third-party analytics scripts.
